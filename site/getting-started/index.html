    Getting started with GLF

    Start with a working table, then add one rule at a time. GLF's VPX runtime is configured in VBScript; exported MPF YAML is useful for comparison but is not a general configuration input to VPX. See Configuration and YAML.

    Choose your starting point

    To build a game from an empty VPX table, follow Build Your First GLF Game. It includes the object checklist, a cumulative script and a complete-game checkpoint. To start from the supplied example table instead, follow Environment Setup. Keep its working trough, plunger, switch wiring and table hooks while learning the rules system. For an existing VPX table, follow Installation, including the collections, timer and initialization, exit, key and option hooks.

    The example table keeps game setup in scripts/src/game/_configuration.vbs, modes in scripts/src/game/modes/, and its bundled framework in scripts/src/glf/glf.vbs. The GLF repository's editable framework source is under scripts/src/; the game may bundle a different revision.

    First playable rule

    1. Verify that a game starts, serves a ball and advances correctly after a drain. Use the trough and plunger tutorials if needed.
    2. Choose an existing switch and confirm its <switch_name>_active event. Use the exact name from the table.
    3. Add a small mode that starts on ball_started, stops on ball_will_end, and awards points with a variable player. Call its creation sub during configuration before Glf_Init.
    4. Rebuild the table script and restart play. Confirm one hit awards points once, including for a second player.
    5. Add feedback with a light player, show or sound.

    Follow the complete mode walkthrough when you are ready to add qualification and a timed objective.
